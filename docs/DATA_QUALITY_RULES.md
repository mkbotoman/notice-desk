# Data-quality rules

As implemented in `scripts/ingest/`. Every fix or flag becomes one entry in
`data/reports/data-quality.json` with its rule ID. Thresholds and spelling tables live in
`scripts/ingest/rules/config.ts`; the DQ-AR floor thresholds live in `src/domain/aging.ts`.

Actions: **fixed** (value was repaired), **flagged** (kept as is, needs a human look), **dropped**
(row removed). Severity: error, warning, info.

| Rule           | File                 | What it checks                                                                                                      | What happens                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DQ-DATE        | all                  | Non-ISO dates (`MM/DD/YYYY`, `M/D/YY`, "Sept 28 2026", Excel serials); lease ending before it starts                | Converted to ISO (info, fixed). Unreadable dates become empty (warning, flagged). Slash dates are read month-first; the profile showed no value above 12 in the first position.                                                                                                                                                                                                                      |
| DQ-MONEY       | leases, notices      | `$`, commas, parentheses, text such as "Pending"                                                                    | Converted to cents (info, fixed). Text or a negative where none is allowed becomes empty (warning, flagged). Tenant credits (negative balances) are allowed.                                                                                                                                                                                                                                         |
| DQ-ENUM        | all                  | Spellings of type, stage, owner, lease status, COI status, aging, lender notice                                     | Known spellings pass silently; recognised aliases are mapped (info, fixed); unknown values use a fallback (warning, flagged). A notice with no usable stage is dropped (error).                                                                                                                                                                                                                      |
| DQ-TENANT      | all                  | Tenant name variants                                                                                                | Exact matches after normalizing case, punctuation, entity suffixes, "dba" and a leading "The" are merged (info, fixed). Names within edit distance 2 are flagged, not merged. A row with no tenant name is dropped. A notice naming a different tenant than its lease uses the lease's tenant (warning).                                                                                             |
| DQ-PROP        | notices              | `property_name` differs from the lease's property                                                                   | Trusts the lease join, records the alias on the property. Info when it looks like an abbreviation, warning when it does not.                                                                                                                                                                                                                                                                         |
| DQ-ORPHAN      | leases, notices, coi | Lease with an unknown property; notice with an unknown lease; COI row with no property or no matching lease         | Kept without the missing link (warning, flagged). Leases with no property show under "Unknown property" and are visible only to all-property personas.                                                                                                                                                                                                                                               |
| DQ-DUP         | all                  | Duplicate primary keys; rows with no key                                                                            | The most complete row is kept (warning, dropped for the rest); keyless rows are dropped (error).                                                                                                                                                                                                                                                                                                     |
| DQ-STAGE       | notices              | A status that names an end state (Cured, Closed, In Collections, Collections Settled) that disagrees with the stage | Stage wins (warning, flagged).                                                                                                                                                                                                                                                                                                                                                                       |
| DQ-CURE        | notices              | Blank, unreadable or unit-less cure periods                                                                         | Blank on a sent notice, or unreadable, becomes `unknown` (warning, flagged): a missing deadline, not "no deadline". Blank on an unsent notice is `none`, silently. A day count with no unit is read as calendar days (info, fixed). A cure period with no send date is flagged.                                                                                                                      |
| DQ-AMOUNT      | notices vs leases    | Notice amount differs from the live balance by more than 5% or more than $500                                       | Both kept (warning, flagged).                                                                                                                                                                                                                                                                                                                                                                        |
| DQ-COI         | coi                  | Exported status disagrees with the expiry date as of the data date                                                  | Exported status kept; the app computes the effective status at the current as-of date (warning, flagged).                                                                                                                                                                                                                                                                                            |
| DQ-COI-MISSING | coi                  | A lease the insurance tool has no row for                                                                           | A `missing` COI record is created, and counts as an insurance signal on the watchlist (warning, flagged).                                                                                                                                                                                                                                                                                            |
| DQ-AR          | leases               | Recorded aging against the balance                                                                                  | Infers only a floor: with n charges open, the oldest is at least (n − 1) months old. Recorded aging better than the floor is an error (understated). A zero balance with non-current aging is stale (warning). A credit is info. Missing rent means it can't be checked (warning). Overstated aging is never flagged, because partial payments lower the balance. `arAgingImplied` stores the floor. |
| DQ-SUITE       | leases               | Two leases on the same property and suite                                                                           | Both kept (warning, flagged).                                                                                                                                                                                                                                                                                                                                                                        |
| DQ-NOTE        | notices              | `updates` that don't follow "M/D/YY - text; M/D/YY - text"                                                          | Kept as one note dated on the send date (warning, flagged).                                                                                                                                                                                                                                                                                                                                          |
| DQ-PII         | notices              | SSN-shaped text, or digits following an account keyword, in free text                                               | Redacted before saving; only the count is logged (warning, fixed). The `guarantor_ssn` column is removed at the CSV parser and never stored. A final check refuses to write output containing a dashed SSN shape.                                                                                                                                                                                    |

## On the real export

187 issues: DQ-DATE 138 (all conversions), DQ-COI-MISSING 19, DQ-CURE 14 (all "assumed calendar
days"), DQ-PROP 7, DQ-COI 2, DQ-MONEY 2, DQ-ORPHAN 2, DQ-TENANT 2, DQ-SUITE 1. DQ-AR, DQ-AMOUNT,
DQ-STAGE, DQ-DUP, DQ-NOTE and DQ-PII found nothing.
